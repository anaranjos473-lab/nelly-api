# ROADMAP COMERCIAL NELLY COMMERCE V1

## Estado

Propuesto como fase de expansion post-piloto.

## Proposito

Definir la evolucion comercial de Nelly hacia una plataforma omnicanal, sin convertir esta linea de trabajo en un proyecto paralelo ni interferir con el piloto controlado de Nelly Delivery.

## Regla de alcance

Este roadmap no forma parte del piloto.

Su activacion solo debe ocurrir cuando se cumplan estas condiciones:

1. El piloto controlado haya sido certificado.
2. Nelly Delivery este operando de forma estable.
3. Nelly Store este creada y funcional.
4. Exista evidencia financiera y operativa suficiente para escalar.

## Tesis

Nelly no debe crecer como una coleccion de canales desconectados.

Debe evolucionar como un nucleo de comercio inteligente que coordina:

- Delivery local.
- Nelly Store.
- Marketplace propio.
- Integraciones externas.
- Inventario.
- Finanzas.
- Automatizacion e IA.

La idea central es simple: el core decide, los canales conectan.

## Lectura estrategica

La secuencia recomendada es:

1. Consolidar el piloto de Nelly Delivery.
2. Abrir Nelly Store como laboratorio comercial controlado.
3. Formalizar Nelly Commerce como capa omnicanal.
4. Incorporar IA y automatizacion sobre datos reales.
5. Escalar hacia canales externos solo con evidencia.

## Fase 1. Consolidacion operativa

Objetivo:

- estabilizar la operacion real;
- confirmar entregas correctas;
- medir tiempos;
- validar la trazabilidad;
- evitar que el crecimiento comercial se apoye sobre una base inmadura.

KPI sugeridos:

- pedidos completados;
- tiempo de entrega;
- incidencias por etapa;
- satisfaccion operativa;
- estabilidad del backend;
- consistencia entre paneles.

## Fase 2. Nelly Store

Objetivo:

Habilitar una tienda propia pequena y controlada para probar el nucleo comercial con bajo riesgo.

Alcance inicial:

- catalogo reducido;
- inventario unificado;
- precios controlados;
- pagos;
- devoluciones;
- facturacion;
- sincronizacion con Delivery.

La tienda debe funcionar como laboratorio de negocio, no como despliegue masivo.

## Fase 3. Nelly Commerce

Objetivo:

Consolidar el nucleo omnicanal que pueda coordinar varios canales sin mutar el core.

Canales previstos:

- Amazon;
- Mercado Libre;
- Shopify;
- WooCommerce;
- WhatsApp Business;
- venta directa B2B;
- comercio local;
- futuros canales que respeten el mismo contrato.

Principio de integracion:

Cada canal debe entrar como conector y no como reinvencion del dominio.

## Fase 4. Motor inteligente comercial

Objetivo:

Usar la data generada por la operacion real para automatizar decisiones de negocio.

Capacidades esperadas:

- prediccion de demanda;
- recomendacion de reposicion;
- deteccion de ruptura de stock;
- calculo de margen;
- comparacion de precios;
- publicacion y despublicacion automatica;
- generacion de reportes ejecutivos;
- deteccion de fraude o anomalias.

## Fase 5. Escalamiento fisico y externo

Objetivo:

Escalar solamente cuando la operacion ya muestre retorno claro.

Posibles extensiones:

- centro de distribucion;
- almacenes regionales;
- dark stores;
- operadores logisticos externos;
- Amazon FBA o mecanismos equivalentes;
- Mercado Libre Full u opciones equivalentes.

## Principios de gobierno

1. No abrir una capa nueva si la anterior no esta estable.
2. No mover el core para acomodar un canal.
3. No escalar sin evidencia financiera y operativa.
4. No agregar complejidad si no mejora la decision.
5. No convertir la expansion comercial en una fuga de foco del piloto.

## Impactos a validar

Antes de activar esta roadmap, debe revisarse el impacto en:

- Android NellyDriver;
- backend;
- panel operativo;
- dashboard comercial;
- CRM;
- metricas y tiempos;
- compatibilidad con el piloto.

## Criterio de adopcion

El roadmap solo pasa de propuesta a ejecucion cuando:

- Nelly Delivery esta certificado;
- Nelly Store esta operativa;
- existen metricas repetibles;
- la operacion local deja margen positivo;
- la expansion omnicanal tiene caso de negocio.
