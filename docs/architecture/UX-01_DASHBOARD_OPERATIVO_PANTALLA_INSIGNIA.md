# UX-01 - Dashboard Operativo Pantalla Insignia

**Estado:** En preparacion  
**Ambito:** Web Nelly  
**Fecha:** 2026-07-25

## 1. Objetivo

Convertir el Dashboard Operativo en la pantalla insignia de Nelly, con una jerarquia visual clara, informacion en tiempo real y lectura ejecutiva de la operacion.

## 2. Alcance

La migracion UX-01 debe concentrarse en:

- header ejecutivo;
- KPIs jerarquizados;
- timeline vivo;
- mapa protagonista;
- centro de alertas;
- actividad en tiempo real;
- panel lateral contextual;
- acciones rapidas.

## 3. Fuera de alcance

- no cambia la logica de negocio;
- no introduce nuevas fuentes de verdad;
- no abre aun el showcase visual;
- no redefine el backend;
- no modifica contratos certificados.

## 4. Principio de ejecucion

Primero se ordena la experiencia. Luego se refinan componentes y solo despues se considera una galeria visual de referencia para acelerar el resto de migraciones.

## 5. Resultado esperado

El Dashboard Operativo debe funcionar como referencia maestra para el lenguaje visual de Nelly y servir como base para CRM, Dashboard Comercial y Panel Admin.
