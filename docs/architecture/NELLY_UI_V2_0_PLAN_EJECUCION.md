# NELLY UI 2.0 - Plan de Ejecucion por Sprints

**Estado:** Plan operativo  
**Ambito:** Dashboard Operativo de Nelly  
**Fecha:** 2026-07-25

## 1. Objetivo

Traducir la propuesta y el checklist de NELLY UI 2.0 en una secuencia de ejecucion por sprints para convertir el Dashboard Operativo en la pantalla insignia de Nelly.

## 2. Principio de trabajo

El Dashboard Operativo se evoluciona como experiencia de producto.

Cada cambio debe mejorar la lectura, la decision o la confianza operativa. No se aprueban cambios por estetica aislada.

## 3. Sprints

### Sprint 1 - Jerarquia narrativa

Objetivo:
- definir la historia principal de la pantalla;
- ordenar la lectura desde el estado general hacia el detalle.

Entregables:
- secuencia de lectura clara;
- encabezado de estado general;
- jerarquia de bloques validada.

### Sprint 2 - Estructura visual

Objetivo:
- consolidar cabecera, KPIs, consumidores y proyecciones.

Entregables:
- cabecera con tiempo real y estado;
- KPIs como lectura primaria;
- consumidores como soporte tactico;
- proyecciones como cierre.

### Sprint 3 - Accion y decision

Objetivo:
- convertir la pantalla en soporte de decision rapida.

Entregables:
- lectura de sano / atencion / accion;
- reduccion de ruido visual;
- acciones secundarias simplificadas.

### Sprint 4 - Estados y legibilidad

Objetivo:
- reforzar estados visibles y claridad de lectura.

Entregables:
- loading;
- empty state;
- warning;
- error;
- real-time;
- espaciado y tipografia consistentes.

### Sprint 5 - Consolidacion final

Objetivo:
- cerrar la pantalla como referencia maestra.

Entregables:
- reduccion de bloques redundantes;
- bloque principal fortalecido;
- experiencia final de consola de control.

## 4. Orden recomendado

1. Jerarquia narrativa.
2. Estructura visual.
3. Accion y decision.
4. Estados y legibilidad.
5. Consolidacion final.

## 5. Criterios de cierre

El plan de ejecucion de UI 2.0 se considera listo cuando:

- la pantalla se lee como una historia de la operacion;
- el operador entiende el estado en segundos;
- los estados visuales son claros;
- la experiencia se siente como una consola de control.
