Dejar constancia de la evidencia base necesaria para revisar el ecosistema comercial como un unico sistema.

## 2. Fuente de verdad

La evidencia se apoya en:

- `GOAL-C2-001 - CRM Basico`
- `GOAL-C3-001 - Fidelizacion Basica`

- misma SSOT certificada;
- misma base de historial real;
- misma derivacion de oportunidades;
- misma logica de sugerencias manuales;
- misma trazabilidad documental.

## 4. Lectura operativa

El Gate G1 sirve para confirmar que el ecosistema comercial:

- no repite reglas;
- no contradice metricas;
- no crea fuentes paralelas;
- conserva continuidad entre las capas ya implementadas.

## 5. Restricciones

- no introducir nuevas capacidades;
- no modificar el core para validar el gate;
- no crear modelos de datos paralelos.
