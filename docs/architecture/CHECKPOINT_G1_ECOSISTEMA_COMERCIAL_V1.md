**Estado:** Punto de control activo  
**Ambito:** Plataforma Nelly OS  
**Gate asociado:** `GOAL-G1-001`

## 1. Proposito

Dejar un punto de control formal para el ecosistema comercial antes de abrir nuevas capacidades. Este checkpoint no agrega funcionalidad; consolida la revision transversal de `C2`, `C3`, `C4`, `C5` y `Q1`.

## 2. Alcance

El checkpoint incluye:

- revision de consistencia entre CRM, fidelizacion, inteligencia comercial, promociones ligeras y calidad operativa;
- confirmacion de una sola SSOT;
- ausencia de reglas duplicadas;
- ausencia de indicadores contradictorios;
- trazabilidad documental en indice maestro, biblioteca de goals y matrices.

## 5. Criterio del checkpoint

El checkpoint se considera activo cuando:

- todas las capas consumen la misma SSOT;
- las metricas principales permanecen coherentes;
- Q1 alimenta C4 y C5 sin mezclar responsabilidades;
- el ecosistema comercial puede leerse como un solo sistema.

## 6. Restricciones

- no abrir C6;
- no introducir nuevas fuentes de verdad;
- no crear reglas comerciales o operativas duplicadas;
- no modificar el core para este checkpoint.
