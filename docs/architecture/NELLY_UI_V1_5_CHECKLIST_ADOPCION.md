# NELLY UI 1.5 - Checklist de Adopcion de Iconografia

**Estado:** Checklist operativo  
**Ambito:** Plataforma web de Nelly  
**Fecha:** 2026-07-25

## 1. Objetivo

Convertir la especificacion de iconografia de NELLY UI 1.5 en una lista de adopcion concreta para implementar, validar y cerrar la biblioteca oficial.

## 2. Alcance

Este checklist aplica a:

- Dashboard Operativo;
- Dashboard Comercial;
- CRM;
- Panel Admin;
- Cocina;
- Repartidor Web;
- componentes compartidos del Design System.

## 3. Checklist de implementacion

### 3.1 Definicion

- [ ] Definir el icono oficial de cada concepto base.
- [ ] Registrar cada icono en la biblioteca oficial.
- [ ] Alinear la nomenclatura con la arquitectura de Nelly UI.
- [ ] Evitar alias o duplicados para un mismo concepto.

### 3.2 Consistencia

- [ ] Unificar pedidos, repartidores, comercios y clientes.
- [ ] Unificar finanzas, configuracion, alertas e incidencias.
- [ ] Unificar mapa, tiempo real, cocina, marketplace e IA.
- [ ] Verificar que el mismo concepto se represente igual en todos los paneles.

### 3.3 Integracion

- [ ] Sustituir iconos locales por la referencia oficial.
- [ ] Aplicar iconos en tarjetas KPI.
- [ ] Aplicar iconos en botones de accion cuando corresponda.
- [ ] Aplicar iconos en estados de carga, vacio, error y tiempo real.

### 3.4 Accesibilidad

- [ ] Confirmar etiqueta o texto alternativo en acciones con icono.
- [ ] Verificar contraste sobre superficies oscuras.
- [ ] Evitar iconos decorativos sin proposito operativo.
- [ ] Confirmar que los iconos no compiten con el texto principal.

### 3.5 Validacion

- [ ] Revisar consistencia visual en escritorio.
- [ ] Revisar consistencia visual en mobile.
- [ ] Confirmar que no se mezclan estilos de sets distintos.
- [ ] Validar que la iconografia acelera la lectura operativa.

## 4. Criterios de cierre

La adopcion de iconografia se considera lista cuando:

- cada dominio tiene un icono principal estable;
- no existen variaciones locales sin justificacion;
- la lectura visual es consistente entre paneles;
- la biblioteca puede reutilizarse en Android sin redefinirse.

## 5. Historial

- 2026-07-25: se crea el checklist de adopcion de iconografia para NELLY UI 1.5.
