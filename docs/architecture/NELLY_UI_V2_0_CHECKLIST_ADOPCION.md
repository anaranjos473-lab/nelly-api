# NELLY UI 2.0 - Checklist de Adopcion UX del Dashboard Operativo

**Estado:** Checklist operativo  
**Ambito:** Dashboard Operativo de Nelly  
**Fecha:** 2026-07-25

## 1. Objetivo

Convertir la propuesta UX de NELLY UI 2.0 en una secuencia de adopcion concreta para evolucionar el Dashboard Operativo como pantalla insignia.

## 2. Alcance

Este checklist aplica al Dashboard Operativo y a las piezas visuales que estructuran su lectura:

- cabecera;
- KPIs;
- consumidores;
- proyecciones;
- estados;
- acciones rapidas.

## 3. Checklist de adopcion

### 3.1 Jerarquia narrativa

- [ ] Definir la historia principal de la pantalla.
- [ ] Ordenar la lectura desde el estado general hacia el detalle.
- [ ] Mantener una prioridad clara entre lectura operativa y soporte analitico.
- [ ] Evitar bloques que compitan entre si por atencion.

### 3.2 Estructura visual

- [ ] Validar cabecera con estado general visible.
- [ ] Validar KPIs como lectura primaria.
- [ ] Validar consumidores como soporte tactico.
- [ ] Validar proyecciones como cierre de lectura.

### 3.3 Accion y decision

- [ ] Verificar que la pantalla permite entender que esta sano.
- [ ] Verificar que la pantalla permite entender que requiere atencion.
- [ ] Verificar que la pantalla permite entender que necesita accion.
- [ ] Reducir todo elemento que no ayude a decidir.

### 3.4 Estados

- [ ] Confirmar loading visible.
- [ ] Confirmar empty state visible.
- [ ] Confirmar warning visible.
- [ ] Confirmar error visible.
- [ ] Confirmar estado real-time visible.

### 3.5 Legibilidad

- [ ] Reducir ruido visual innecesario.
- [ ] Mantener jerarquia tipografica clara.
- [ ] Mantener espaciado consistente entre bloques.
- [ ] Mantener lenguaje de estado uniforme.

### 3.6 Evolucion

- [ ] Simplificar bloques redundantes.
- [ ] Fortalecer el bloque principal de lectura.
- [ ] Simplificar acciones secundarias.
- [ ] Ajustar la pantalla solo cuando mejore la decision operativa.

## 4. Criterios de cierre

La adopcion UX del Dashboard Operativo se considera lista cuando:

- la pantalla se entiende en segundos;
- la operacion se lee como una historia clara;
- los estados son evidentes;
- la experiencia se siente como una consola de control y no como una coleccion de tarjetas.

## 5. Historial

- 2026-07-25: se crea el checklist de adopcion UX para NELLY UI 2.0.
