# NELLY UI V1.0 - Congelamiento Documental

**Estado:** Activo  
**Ambito:** Documentacion estructural de NELLY UI  
**Fecha:** 2026-07-25

## 1. Proposito

Congelar la documentacion estructural base de NELLY UI para evitar crecimiento innecesario y centrar el esfuerzo en la ejecucion visible del producto.

## 2. Alcance congelado

Quedan congelados como base de referencia:

- NELLY UI V1.0 Plan
- NELLY UI V1.0 Arquitectura
- NELLY UI V1.1 Estados

- NELLY UI V1.3 Especificacion oficial

- NELLY UI V2.0 Dashboard Operativo UX
- NELLY UI V2.0 Checklist de adopcion
- NELLY UI V2.0 Plan de ejecucion
- Index maestro UI

## 3. Regla operativa

- No crear nuevos documentos estructurales si el cambio puede resolverse con ejecucion, ajuste de codigo o actualizacion puntual de un documento existente.
- Cualquier nuevo material documental debe responder a una necesidad real de implementacion, certificacion o cierre.
- El siguiente foco de trabajo debe ser productivo y visible.

## 4. Excepcion permitida

Se permite crear documentacion nueva solo si:

- evita una regresion;
- habilita una migracion concreta;
- sirve como evidencia de una certificacion;
- o reduce ambiguedad en una implementacion activa.

## 5. Criterio de cierre

La congelacion se considera util cuando la documentacion deja de crecer por inercia y pasa a servir como soporte estable para la ejecucion.
