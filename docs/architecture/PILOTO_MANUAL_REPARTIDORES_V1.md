# PILOTO MANUAL REPARTIDORES V1

**Estado:** Guia operativa breve  
**Ambito:** Repartidores participantes en piloto controlado  
**Referencia:** `OV1_PRE_PILOTO_GATE_V1.md`

## 1. Objetivo

Dar al repartidor una guia simple para completar entregas durante el piloto con evidencia suficiente y sin romper el flujo operativo certificado.

## 2. Antes de iniciar

El repartidor debe confirmar:

- acceso a la aplicacion;
- disponibilidad durante el turno;
- bateria y conexion;
- canal de soporte;
- conocimiento del proceso de deuda si aplica.

## 3. Flujo basico

1. Revisar pedidos disponibles.
2. Aceptar solo pedidos que pueda atender.
3. Llegar al comercio y confirmar recoleccion.
4. Entregar al cliente.
5. Completar la entrega desde la app.
6. Reportar incidencias de direccion, empaque, producto, cliente o pago.

## 4. Informacion que debe vigilar

| Elemento | Que revisar |
| --- | --- |
| Pedido | Comercio, cliente, direccion y monto |
| Recoleccion | Producto correcto y empaque en buen estado |
| Entrega | Hora, confirmacion y estado final |
| Incidencias | Reportar causa y evidencia cuando aplique |
| Deuda | Mantener el estado financiero dentro de reglas |

## 5. Que no debe hacer

- No aceptar pedidos que no pueda completar.
- No cerrar una entrega si el pedido no fue entregado.
- No omitir incidencias de producto o empaque.
- No intentar bypass de bloqueo por deuda.

## 6. Criterio de exito del repartidor

El repartidor opera correctamente cuando acepta, recoge, entrega y cierra pedidos sin apoyo constante, manteniendo trazabilidad de incidencias y pagos.
