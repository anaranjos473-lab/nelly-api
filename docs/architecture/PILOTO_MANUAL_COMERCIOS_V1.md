# PILOTO MANUAL COMERCIOS V1

**Estado:** Guia operativa breve  
**Ambito:** Comercios participantes en piloto controlado  
**Referencia:** `OV1_PRE_PILOTO_GATE_V1.md`

## 1. Objetivo

Dar al comercio una guia simple para operar pedidos durante el piloto sin depender de soporte constante.

## 2. Antes de iniciar

El comercio debe confirmar:

- acceso al panel correspondiente;
- horario de operacion;
- productos disponibles;
- persona responsable del piloto;
- canal de soporte acordado.

## 3. Flujo basico

1. Revisar pedidos entrantes.
2. Confirmar preparacion.
3. Marcar el pedido como listo cuando corresponda.
4. Verificar que el repartidor recoja el pedido correcto.
5. Reportar cualquier incidencia de producto, empaque, tiempo o entrega.

## 4. Informacion que debe vigilar

| Elemento | Que revisar |
| --- | --- |
| Pedido | Cliente, direccion, items y monto |
| Tiempo | Preparacion y salida |
| Producto | Correcto, completo y en buen estado |
| Empaque | Sellado, sin derrames ni dano visible |
| Incidencias | Reportarlas en cuanto ocurran |

## 5. Que no debe hacer

- No duplicar pedidos manualmente si existe duda.
- No modificar informacion fuera del flujo acordado.
- No cerrar incidencias sin registrarlas.
- No usar datos fuera de la SSOT del piloto.

## 6. Criterio de exito del comercio

El comercio opera correctamente cuando puede recibir, preparar y entregar pedidos al repartidor sin ayuda constante y reporta incidencias de forma clara.
