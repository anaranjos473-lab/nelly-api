# INDEX U1 - PLATAFORMA UNIVERSAL V1

## Proposito
Servir como puerta de entrada tecnica para la nueva etapa U1, orientada a un modelo de dominio universal que pueda soportar Kitchen, marketplace, inventario, integraciones y finanzas sin rediseñar la plataforma desde cero.

## Uso recomendado
1. Leer el plan formal de U1.
2. Revisar el ADR base de dominio universal.
3. Entender la relacion entre fulfillment, ledger e inventario.
4. Consultar la linea base cerrada de B2/B3 antes de iniciar cualquier cambio.
5. Usar este indice como puente entre el cierre anterior y el nuevo dominio.
