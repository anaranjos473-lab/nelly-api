# GUIA DE LECTURA PLATAFORMA

## Proposito
Servir como portada minima para entender el recorrido de la plataforma Nelly sin tener que recorrer primero todo el historial del repositorio.

## ¿Que es Nelly Platform?
Nelly Platform es una plataforma operativa y de cumplimiento basada en una fuente unica de verdad, con estado centralizado, contratos canonicos, validacion de flujos y una evolucion controlada por evidencias.

## ¿Por donde empezar?
1. Abrir `INDEX_MAESTRO_PLATAFORMA_V1.md`.
2. Revisar la estabilizacion base B.
3. Leer U1 para entender la arquitectura universal.
4. Leer U2 para ver el nucleo implementado.
5. Leer U3 para entender la migracion progresiva.
6. Revisar el programa operativo P1-P5.
7. Consultar RC1 como referencia de congelamiento y salida controlada.
