# NELLY UI V1.1 - Iconografia

**Estado:** Propuesto  
**Ambito:** Plataforma web de Nelly  
**Fecha:** 2026-07-25

## 1. Objetivo

Unificar los simbolos visuales de toda la plataforma para que cada dominio use una referencia unica y consistente.

## 2. Biblioteca base

- Pedidos
- Repartidores
- Comercios
- Clientes
- Finanzas
- Configuracion
- Incidencias
- Reportes
- Radar
- CRM

## 3. Regla de uso

- Un concepto, un icono principal.
- La iconografia debe ser consistente entre paneles y estados.
- No mezclar estilos de sets distintos dentro de una misma pantalla.

## 4. Criterio de calidad

La iconografia es correcta si acelera el reconocimiento sin competir con la informacion operativa.
