# C5 EVIDENCIA PROMOCIONES LIGERAS V1

**Estado:** Evidencia estructural consolidada  
**Ambito:** Plataforma Nelly OS  
**Goal asociado:** `GOAL-C5-001`

## 1. Objetivo

Dejar constancia de la primera integracion funcional de C5 como capa ligera de promociones sobre la SSOT certificada y sobre las oportunidades de C4.

## 2. Fuente de verdad

La evidencia se apoya en:

- `GOAL-C4-001 - Inteligencia Comercial`
- `GOAL-C5-001 - Promociones Ligeras`

No se crean fuentes paralelas ni se altera el core operativo.

## 3. Evidencia observada

La integracion muestra:

- un bloque nuevo `C5 · Promociones Ligeras` en el Dashboard Comercial;
- sugerencias manuales derivadas de las oportunidades comerciales;
- reutilizacion de la proyeccion `commercial_insights`;
- continuidad con las vistas C1, C2, C3 y C4;
- ausencia de automatizacion compleja o nueva fuente de verdad.

## 4. Lectura operativa

La primera iteracion de C5 confirma que:

- las promociones ligeras pueden derivarse de la evidencia ya certificada;
- la capa comercial puede sugerir acciones manuales simples;
- C5 se mantiene ligero y trazable;
- el dashboard conserva su coherencia operativa.

## 5. Restricciones

- no automatizar campanas;
- no introducir scoring predictivo;
- no crear una nueva base de datos;
- no modificar el core para producir estas sugerencias.

## 6. Criterio de continuidad

Esta evidencia permite continuar C5 hacia una validacion funcional en navegador autenticado y, posteriormente, a una certificacion completa de la primera version de promociones ligeras.
