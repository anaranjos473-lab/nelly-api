# CRITERIOS PARA PILOTO CON COMERCIOS REALES

## Condiciones minimas

- expediente del piloto controlado consolidado;
- baseline certificado intacto;
- doctor operativo en `OPERABLE`;
- mecanismos de soporte y contingencia definidos;
- criterios de pausa y cierre disponibles.

## Criterios de aceptacion

| Criterio | Estado esperado |
| --- | --- |
| Flujo operativo principal | Estable |
| Cierre de pedidos | Limpio |
| Monitoreo | Activo |
| Evidencia | Completa |
| Soporte | Disponible |

## Recomendacion

No ampliar a comercios reales hasta que el expediente ejecutivo y el monitoreo continuo esten completamente alineados.
