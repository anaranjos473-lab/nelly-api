# Archived Certification Scripts

Estos scripts se usaron como evidencia operativa durante `PILOTO_CAMPO_001`.

No forman parte del flujo certificado de runtime ni del tooling rutinario. Algunos escriben directamente en Firebase o ejecutan pruebas contra produccion, por lo que deben tratarse como material historico/forense y no como comandos seguros para operacion diaria.

Para repetir una certificacion futura, crear scripts nuevos y revisados para el entorno actual en vez de ejecutar estos archivos sin auditoria previa.
