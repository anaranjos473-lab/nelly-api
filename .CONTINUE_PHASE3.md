## 🔧 DETALLES TÉCNICOS PARA DEBUGGING

### Si APK no compila
**Checklist**:
- [ ] ¿Android SDK instalado? (`adb version`)
- [ ] ¿Gradle wrapper válido? (`./gradlew.bat --version`)
- [ ] ¿Java 11+ instalado? (`java -version`)
- [ ] ¿Permisos de escritura en carpeta app/build?

**Comando de limpieza**:
```powershell
./gradlew.bat clean --refresh-dependencies
./gradlew.bat assembleDebug
```

### Si no aparece botón en dispositivo
**Debug pasos**:
1. Verificar APK correcta instalada: `adb shell pm list packages | grep nelly`
2. Revisar logs: `adb logcat | grep "NellyAppStart"`
3. Verificar Firebase auth tokens válidos
4. Revisar RTDB: ¿Hay pedidos con estado=LISTO en `pedidos_para_reparto`?

**Logcat buscar**:
```powershell
adb logcat -s NellyAppStart
# Buscar líneas con estado de pedidos
```

### Si falla complete-order en E2E
**Verificar**:
1. Backend sigue respondiendo: `curl https://nelly-api-8lh1.onrender.com/health`
2. Transacción se ejecuta sin error (revisar logs Render)
3. Finanzas se registran correctamente (revisar RTDB `repartidores/{uid}/finanzas`)
