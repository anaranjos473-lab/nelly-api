# Prompt Library

This folder contains reusable Copilot/Agent prompts for Nelly OS.

## Available prompts

- `nelly-dev-lead.prompt.md`: backend, panel and CI/CD orchestration
- `nelly-agent-master.prompt.md`: deep modular analysis with subagents
- `nelly-rca.prompt.md`: forensics-first root cause analysis with no-code investigation phase
- `nelly-agent-daily.prompt.md`: short daily prompt for quick tasks
- `nelly-backend.prompt.md`: backend Node.js focused prompt
- `nelly-firebase.prompt.md`: Firebase RTDB / Firestore focused prompt
- `nelly-android.prompt.md`: Android repository and lifecycle focused prompt

## Suggested use

- Use the master prompt for cross-cutting investigations.
- Use the domain prompts when the task is clearly scoped.
- Keep prompts small and evidence-driven.
