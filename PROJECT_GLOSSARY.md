# PROJECT_GLOSSARY.md

| Term | Meaning |
| --- | --- |
| Radar | Screen where the driver receives available orders. |
| Pedido Activo | Order currently assigned to the driver. |
| Presencia | Live availability / connectivity state of a driver. |
| Complete Order | Final closure of a delivery. |
| CICP | Certification of Integrity and Persistence Consistency. |
| ICV | Lifecycle Investigation. |
| Baseline | Certified reference state used for comparison. |
| SSOT | Single Source of Truth. |
| ENTREGADO | Final delivered state. |
| LISTO | Order available for assignment. |
| EN_CURSO | Order currently in delivery. |
| `repartidores/{uid}` | Canonical driver profile and operative state. |
| `repartidores_activos/{uid}` | Presence / live telemetry overlay. |
| `pedidos/{pedidoId}` | Canonical order record. |

## Usage

Use these terms consistently in code, docs, ADRs, and investigations.
